# .NET Курс - Блок 0: Инструменты и качество кода

## Описание
Этот репозиторий содержит шаблон проекта для блока 0 курса по C#. Цель блока - освоить инструменты обеспечения качества кода и правильной организации проекта.

## 🎯 Цели обучения
- Настроить рабочее окружение для .NET разработки
- Освоить базовые практики работы с Git
- Настроить и использовать EditorConfig для форматирования
- Интегрировать Roslyn Analyzers для статического анализа
- Научиться работать с тестами и CI

## 🛠 Необходимые инструменты
- [Документация dotnet](https://learn.microsoft.com/ru-ru/dotnet/)
- [.NET 8.0 SDK (LTS)](https://dotnet.microsoft.com/download/dotnet/8.0)
- IDE: Rider / Visual Studio / VS Code
- [Git](https://git-scm.com/)
- [GitHub CLI](https://cli.github.com/) (опционально)

## 📚 Задания
- [Задание 0: Настройка качества кода](./assignments/assignment-0.md)

## 🏃‍♂️ Как начать работу
1. Сделайте **fork** этого репозитория
2. Клонируйте свой форк локально
3. Выполните задания из файла `assignment-0.md`
4. Создавайте **Pull Request** для проверки

## 🔧 Инструменты качества в проекте
- **EditorConfig** - единое форматирование кода
- **Roslyn Analyzers** - статический анализ кода
- **xUnit** - модульное тестирование
- **GitHub Actions** - непрерывная интеграция
